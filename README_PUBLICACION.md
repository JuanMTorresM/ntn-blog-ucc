# Publicación en GitHub Pages

1. Descarga y descomprime este paquete.
2. Sube el contenido de esta carpeta a la raíz de tu repositorio.
3. Verifica que `index.html` quede en la raíz.
4. Haz commit en la rama `main`.
5. En GitHub Pages usa `main` y `/(root)`.
6. Espera unos minutos y recarga tu enlace público.
